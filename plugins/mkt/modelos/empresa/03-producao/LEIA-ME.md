# Produção

Uma pasta por peça: `AAAA-MM/Sxx_Pnnn_tema-curto/`
- `AAAA-MM`: mês de publicação · `Sxx`: semana do ano · `Pnnn`: número da peça na planilha · `tema-curto`: até 4 palavras, sem acento.

Dentro de cada pasta:
| Arquivo / pasta | Quem gera |
|---|---|
| `roteiro.md` (vídeo) ou `texto.md` (carrossel) | roteiro-video / carrossel |
| `video-bruto/` | você (takes gravados) |
| `edicao/` (transcrição, plano.md, cortes, composição, tempo.md) | editar-reels |
| `video-final/Pnnn-v1.mp4` | editar-reels |
| `carrossel/` (laminas.json, 01.png…, carrossel-linkedin.pdf) | carrossel |
| `revisao-qualidade.md` | controle-qualidade |
| `revisao-estrategica.md` | estrategista-marketing |
| `linkedin.md`, `publicar/` | agendar-publicacao |
